# Corsa Messenger Integrator

Интеграция Telegram, VK и других мессенджеров с amoCRM.

## Возможности

- ✈️ Уведомления в Telegram о новых сделках
- 💬 Сообщения из VK в карточку контакта
- 📝 Создание лидов из сообщений
- 🔔 Вебхуки для событий amoCRM

## Требования

- Аккаунт amoCRM с правами администратора
- Telegram-бот для получения уведомлений
- VK-приложение для интеграции сообществ

## Установка

1. Установите виджет в amoCRM Marketplace
2. Зарегистрируйтесь на corsa-crm.ru
3. Подключите мессенджеры через интерфейс виджета
4. Наслаждайтесь интеграцией!
